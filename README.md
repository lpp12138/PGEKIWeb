# PGEKI Web Configurator

基于 **WebHID** 的PGEKI2配置界面

点击访问喵: [![Github Pages](https://img.shields.io/badge/Github-Pages-green)](https://lpp12138.github.io/PGEKIWeb/)

## ✨ 功能特性ヾ(≧▽≦*)o

- **按键配置**: 可视化配置每个按键的RGB颜色和USB HID键码。
- **多配置文件**: 支持6个独立的配置文件，可随时切换。
- **双USB模式**: 保留原始IO通信，并可从网页切换到实验性的IO4模式。
- **本地存储**: 所有配置都保存在浏览器的本地储存中，刷新页面不会丢失。

## 🚀 如何使用

1.  **连接设备**: 将PGEKI2连接到电脑。
2.  **打开网页**: [![Github Pages](https://img.shields.io/badge/Github-Pages-green)](https://lpp12138.github.io/PGEKIWeb/)
3.  **授权连接**: 点击页面右上角的"连接设备"按钮，在浏览器弹出的授权窗口中选择您的设备并点击"连接"。
4.  **开始配置**:
    -   点击左上角的数字切换不同的配置文件。
    -   点击键盘布局上的任意按键，在弹出的窗口中修改颜色和键码，然后点击"保存"。
    -   当处于**配置文件1**时，侧边栏会出现"接管IO灯光"开关。打开它，可以在IO模式下自定义灯光喵；关闭它，则设备恢复IO灯光接管喵。
    -   在侧边栏的"USB模式"中选择"原始IO（兼容）"或"IO4（实验）"。模式在写入配置后生效，切换时设备会重启，需要重新连接。
5.  **写入配置**: 当您完成一个配置文件的修改后，点击"写入单个配置文件"按钮，即可将当前网页上的配置数据一次性发送到您的设备中。
6.  **保存与载入**:
    -   点击"保存配置"，可以将全部6个配置文件的设置保存为一个.json文件到您的电脑中。
    -   点击"载入配置"，可以选择之前保存的.json文件，将其中的配置恢复到网页上。

## WebHID兼容信息

| 模式 | VID:PID | 配置Report ID |
| --- | --- | --- |
| 原始IO | `0721:0721` | `0x00` |
| IO4 | `0CA3:0021` | `0x10` |

网页发送63字节配置数据：字节0为命令`0x10`，字节1为配置编号`0..5`，字节2到41为10组RGB与键码，字节42为IO灯光接管标志，字节43为目标USB模式（`1`原始IO，`2` IO4）。

配置编号`0`是默认IO配置。设备只有在原始IO模式下、写入并激活编号`1..5`的配置后，才额外枚举合并的键盘/鼠标HID接口；RAW IO接口始终保持独立。
