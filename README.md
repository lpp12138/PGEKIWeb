# PGEKI Web Configurator

基于 **WebHID** 的PGEKI2配置界面

点击访问喵: [![Github Pages](https://img.shields.io/badge/Github-Pages-green)](https://lpp12138.github.io/PGEKIWeb/)

## ✨ 功能特性ヾ(≧▽≦*)o

- **按键配置**: 可视化配置每个按键的RGB颜色和USB HID键码。
- **多配置文件**: 支持6个独立的配置文件，可随时切换。
- **双USB模式**: 配置文件1可在原始IO与实验性的IO4之间切换；配置文件2到6固定使用原始IO键鼠复合模式。
- **侧键传感监控**: 连接控制器后实时显示左右侧键信号曲线，并标注动作/释放阈值、灵敏度、原始值、滤波值和自适应基线。
- **实时摇杆位置**: 中央控制器下方显示与实际 RAW/IO4 输入报告一致的摇杆位置，不增加额外 USB 端点。
- **动作录制与回放**: 固件 `1.1.0` 及之后版本支持8个动作槽，可由网页开始录制、停止并保存、单次或循环回放及删除。
- **版本化固件更新**: 固件更新窗口会列出仓库内 `1.0.0` 及之后的固件，可校验后通过WebHID直接上传；同时保留本地 `.bin` 和板载Wi-Fi OTA入口。
- **自动语言与主题**: 支持简体中文和英文，首次访问按浏览器语言自动匹配，右上角的地球图标可手动切换并保存语言；主题始终跟随系统，并在系统外观变化时即时切换。
- **本地存储**: 所有配置都保存在浏览器的本地储存中，刷新页面不会丢失。

## 🚀 如何使用

1.  **连接设备**: 将PGEKI2连接到电脑。
2.  **打开网页**: [![Github Pages](https://img.shields.io/badge/Github-Pages-green)](https://lpp12138.github.io/PGEKIWeb/)
3.  **授权连接**: 点击页面右上角的"连接设备"按钮，在浏览器弹出的授权窗口中选择您的设备并点击"连接"。
    -   连接成功后，实时传感图表与灵敏度滑块会紧邻主界面控制器图两侧；滑块松开后只写入左右灵敏度，并以固件遥测回读确认同步。旧固件不支持诊断 Feature Report 时，灵敏度区域会提示当前固件不支持调节，不影响其他配置功能。
4.  **开始配置**:
    -   点击左上角的数字切换不同的配置文件。
    -   点击键盘布局上的任意按键，在弹出的窗口中修改颜色和键码，然后点击"保存"。
    -   当处于**配置文件1**时，侧边栏会出现"接管IO灯光"开关。打开它，可以在IO模式下自定义灯光喵；关闭它，则设备恢复IO灯光接管喵。
    -   配置文件1的侧边栏可选择"原始IO（兼容）"或"IO4（实验）"。该设置只属于配置文件1；从IO4切换到配置文件2到6时，设备会自动重启为原始IO键鼠复合模式，需要重新连接。
5.  **写入配置**: 当您完成一个配置文件的修改后，点击"写入单个配置文件"按钮，即可将当前网页上的配置数据一次性发送到您的设备中。
    -   固件版本不低于 `1.1.0` 时，可在中央控制器下方的“动作录制与回放”区域选择槽位。录制会保存按键、摇杆与事件间隔；停止后异步写入设备，状态显示“已保存”后即可回放。动作槽与6个配置文件槽相互独立。
6.  **保存与载入**:
    -   点击"保存配置"，可以将全部6个配置文件的设置保存为一个.json文件到您的电脑中。
    -   点击"载入配置"，可以选择之前保存的.json文件，将其中的配置恢复到网页上。
7.  **更新固件**:
    -   USB方式：先连接设备，在侧边栏打开“固件更新”，直接选择仓库中的 `1.0.0` 或更高版本；也可以选择不超过2 MiB的本地应用固件 `.bin`，再点击“通过USB上传”。仓库固件会在传输前核对大小和SHA-256。
    -   Wi-Fi备用方式：上电后持续按住设备的 `FUNC` 键，等待5秒触摸校准结束并进入OTA模式；连接开放热点 `PGEKI2`，再从固件更新窗口打开 `http://10.10.10.1/`。不支持WebHID更新的旧固件需要先通过此方式完成首次升级。
    -   上传和校验完成前不要断电，设备成功后会自动重启。

## WebHID兼容信息

| 模式 | VID:PID | 配置Report ID | 传感Feature Report ID |
| --- | --- | --- | --- |
| 原始IO | `0721:0721` | `0x00` | `0x00` |
| IO4 | `0CA3:0021` | `0x10` | `0x11` |

网页发送63字节配置数据：字节0为命令`0x10`，字节1为配置编号`0..5`，字节2到41为10组RGB与键码，字节42为IO灯光接管标志。字节43只在配置编号`0`时指定目标USB模式（`1`原始IO，`2` IO4）；写入编号`1..5`时发送`0`，保留编号`0`已保存的模式。

网页通过传感 Feature Report 的字节 `60..62` 读取当前运行固件的主、次、修订版本，并在连接按钮旁显示为 `固件 vX.Y.Z`；旧固件未提供该字段时显示 `固件 v--`。

动作命令复用原有63字节 WebHID OUT 报告，不增加 USB 端点：字节0为 `0x12`，字节1到2为 `41 43`，字节3为协议版本 `1`，字节4为录制、停止、回放或删除操作，字节5为动作槽 `0..7`，字节6的最低位控制循环回放。传感 Feature Report 的字节 `56..59` 返回动作状态、当前槽位与有效槽位位图；不支持该协议的旧固件会自动禁用面板。

配置编号`0`是默认IO配置，也是唯一区分原始IO与IO4的槽位。写入或在机台上选择有效的编号`1..5`后，设备固定枚举原始IO与键盘/鼠标复合接口；切回编号`0`时恢复该槽位保存的原始IO或IO4模式。需要改变USB描述符时设备会自动重启，RAW IO接口始终与键盘/鼠标接口分开。

## 固件素材

可公开更新的应用固件存放在 `firmware/<版本>/`，并登记到 `firmware/manifest.json`。网页只显示符合三段式版本号且不低于 `1.0.0`、大小不超过2 MiB、同时带有效SHA-256的条目，并按版本从新到旧排列。版本说明可通过兼容 schema v1 的 `notesI18n` 字段提供 `zh-CN` 与 `en` 翻译；旧 `notes` 字段继续作为回退文本。
